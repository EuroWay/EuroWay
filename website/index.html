Veelgestelde vragen

Goed om te weten.

Moet ik iets installeren?

Nee. Sprite werkt op iPhone, Mac en in de browser. Koppelingen leg je met een paar klikken; voor software zonder koppeling gebruikt Sprite een eigen cloudbrowser.

Stuurt Sprite zomaar mails of facturen uit?

Nee. Gevoelige stappen, zoals een mail versturen of een factuur boeken, vragen eerst jouw akkoord. Pas als je dat wil, laat je Sprite bepaalde taken zelfstandig afwerken.

Wat is het bedrijfsbrein?

Een overzicht van je klanten, prijzen, kortingen, voorwaarden en procedures. Sprite baseert elke actie op die gegevens en verzint niets.

Ziet Sprite mijn wachtwoorden?

Nee. Je logins worden versleuteld bewaard. Je Sprites loggen ermee in, maar zien je wachtwoord nooit.

Mijn software staat niet in de lijst. Wat nu?

Vraag de koppeling aan. In het Max-plan bouwen we koppelingen op aanvraag, en via de cloudbrowser kan Sprite vaak al meteen in je software werken.
